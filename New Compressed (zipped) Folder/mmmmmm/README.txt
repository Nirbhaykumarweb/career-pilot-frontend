CAREER PILOT DEMO
==================

Files:
- index.html      Main landing page containing the sections shown in the reference PDF.
- login.html      Login screen.
- register.html   Registration screen.
- interview.html  AI interview demo screen.
- style.css       All styling, responsive layouts and visual effects.
- script.js       Demo interactions.

RUN:
1. Keep all files in the same folder.
2. Open index.html in Chrome/Edge.
3. No server is required for the static demo.

The uploaded reference contains the Career Pilot landing page, placement journey,
features, process, AI interviewer, company hub, testimonials, pricing/CTA,
login/register screens and AI interview screen. This package recreates those
screens as a functional static front-end demo. Backend authentication, database,
real AI voice/video and payment processing are not included.
