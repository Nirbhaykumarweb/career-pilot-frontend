Project Introduction

Our project is a student placement tracker that helps learners manage preparation, practice questions, and mock interviews in one place.

Problem Statement

Students often struggle to organize their placement preparation across multiple platforms, leading to poor consistency and limited progress tracking.

Technologies Used

HTML5, CSS3, Bootstrap 5, JavaScript, Font Awesome, Google Fonts.

Architecture

The project follows a simple frontend architecture with separate pages, shared assets, and mock data for demonstration.

Database

Currently mock data is stored in localStorage and static HTML content. Future backend can integrate MongoDB.

Challenges

Managing responsive layouts, ensuring clean routes, and designing a real-world SaaS-like interface with frontend-only constraints.
